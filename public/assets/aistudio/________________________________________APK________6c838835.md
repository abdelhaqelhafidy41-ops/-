# المرحلة السابعة: الاختبار النهائي وبناء APK والإطلاق

## السياق
هذا هو المشروع الكامل لتطبيق نور المسلم بعد تنفيذ المراحل السابقة. لا تضف واجهات جديدة عشوائيًا؛ ركّز على التحقق، إصلاح الأخطاء، الأمان، الأداء، وإخراج نسخة قابلة للاستخدام.

## الهدف
تحويل المشروع إلى نسخة Release حقيقية قابلة للبناء والتثبيت، مع التأكد من أن الوظائف الأساسية تعمل ولا توجد بيانات وهمية أو أزرار غير فعالة.

## الاختبارات الآلية
نفّذ وأصلح حتى النجاح:

```bash
./gradlew test
./gradlew lint
./gradlew assembleDebug
```

وأضف اختبارات UI أو Compose لأهم التدفقات:

1. فتح التطبيق والتنقل.
2. فتح القرآن وقراءة سورة.
3. تشغيل ذكر وعدّه.
4. فتح الصلاة وطلب الموقع.
5. تغيير المظهر.
6. العمل دون إنترنت.
7. حذف البيانات.

## اختبار الأجهزة
اختبر على الأقل:

- Android حديث مع شاشة صغيرة.
- Android حديث مع شاشة كبيرة.
- الوضع الداكن.
- RTL.
- جهاز بلا بوصلة، إن أمكن.
- رفض الموقع.
- رفض الإشعارات.
- اتصال إنترنت ضعيف أو منقطع.
- تغيير المنطقة الزمنية.

## الأمان
- افحص عدم وجود API Keys في Git.
- افحص عدم وجود كلمات مرور أو أسرار.
- استخدم HTTPS فقط.
- راجع صلاحيات AndroidManifest واحذف غير الضروري.
- راجع سياسة الخصوصية.
- نفّذ ProGuard/R8 عند ملاءمته.
- لا تسجل بيانات الموقع أو العبادة في Logcat في نسخة Release.

## الأداء
- راقب زمن فتح الشاشة الرئيسية.
- افحص استهلاك الذاكرة.
- افحص التسريبات.
- افحص البطارية بسبب الإشعارات والمستشعرات.
- أوقف مستشعرات القبلة عند مغادرة الشاشة.
- لا تنفذ استعلامات Room الثقيلة على Main Thread.
- حسّن الصور والخطوط والموارد.

## البيانات والتراخيص
أنشئ ملفًا نهائيًا `DATA_SOURCES.md` يحتوي على:

- مصدر نص القرآن.
- مصدر الصوت.
- مصدر الأذكار والأحاديث.
- مكتبة مواقيت الصلاة.
- مصدر الطقس إن استُخدم.
- الرخصة وشروط الاستخدام لكل مصدر.
- ما إذا كان يلزم API Key.

لا تعتبر المشروع جاهزًا إذا كان أي مصدر غير موثق.

## البناء والإصدار
1. حدّث versionName وversionCode.
2. أنشئ إعدادات Release.
3. ابنِ APK قابلًا للتثبيت:

```bash
./gradlew assembleRelease
```

4. إذا لم يتوفر توقيع نهائي، أنشئ نسخة Release غير موقعة أو وقّعها بمفتاح اختبار، واذكر ذلك بوضوح.
5. لا تضع مفتاح توقيع حقيقي داخل المستودع.
6. تحقق من تثبيت APK وتشغيله.
7. أنشئ ملف `RELEASE_NOTES.md`.

## معيار الإكمال
لا تقل إن المشروع مكتمل إذا:

- بقي زر غير فعال.
- بقيت شاشة وهمية.
- توجد بيانات صلاة ثابتة.
- لا يعمل التطبيق دون إنترنت في الوظائف التي يفترض أن تعمل.
- لا توجد مصادر موثوقة للمحتوى الديني.
- يفشل البناء أو الاختبارات.
