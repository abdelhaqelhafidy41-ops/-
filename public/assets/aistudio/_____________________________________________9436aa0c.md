# المرحلة الأولى: تأسيس مشروع تطبيق نور المسلم

## الدور المطلوب
أنت مهندس Android محترف. ابنِ أساس تطبيق إسلامي حقيقي باسم مؤقت **نور المسلم**، وليس نموذجًا شكليًا أو Prototype. نفّذ المطلوب داخل مشروع قابل للبناء والتشغيل.

## الهدف
إنشاء مشروع Android منظم وقابل للتوسع، مع هوية بصرية أصلية، دعم كامل للعربية وRTL، قاعدة بيانات محلية، بنية Clean Architecture، وتنقل فعلي بين الشاشات.

## التقنية الإلزامية
- Kotlin.
- Jetpack Compose وMaterial 3.
- MVVM أو Clean Architecture.
- Hilt.
- Room.
- DataStore.
- Kotlin Coroutines وFlow.
- Navigation Compose.
- Retrofit أو Ktor عند الحاجة.
- minSdk وtargetSdk مناسبين لأحدث Android Studio المتاح.

## بنية المشروع
أنشئ طبقات واضحة، مثل:

```text
app/
  core/
  data/
    local/
    remote/
    repository/
  domain/
  presentation/
    navigation/
    theme/
    home/
    quran/
    adhkar/
    prayer/
    more/
  notifications/
```

## الهوية والتصميم
- اسم التطبيق القابل للتغيير من ملف إعداد واحد.
- تصميم أصلي مستوحى من التطبيقات الإسلامية الحديثة دون نسخ تطبيق بعينه.
- ألوان: كحلي داكن، أخضر زمردي، ذهبي هادئ، أبيض عاجي.
- وضع فاتح وداكن وتلقائي.
- خطوط عربية واضحة مع دعم تغيير حجم الخط.
- دعم RTL في جميع الشاشات.
- بطاقات مستديرة وشريط تنقل سفلي.
- استخدم Material Icons أو أيقونات مرخصة فقط.

## الشاشات المطلوبة في هذه المرحلة
أنشئ شاشات حقيقية مرتبطة عبر Navigation Compose:

1. الرئيسية.
2. القرآن.
3. الأذكار.
4. الصلاة والقبلة.
5. المزيد.
6. الإعدادات.

يجب أن تحتوي كل شاشة على محتوى أولي غير وهمي من نوع الحالة الفارغة أو رسالة "سيتم تحميل البيانات"، وليس أرقامًا أو نصوصًا دينية مختلقة. كل زر تنقل يجب أن يعمل فعليًا.

## قاعدة البيانات
أنشئ Room entities وDAO وDatabase مبدئية للآتي:

- إعدادات المستخدم.
- المفضلة.
- آخر موضع قراءة.
- سجل الأذكار.
- سجل الإنجازات اليومية.
- مواقيت الصلاة المحفوظة.
- بيانات القرآن، مع تجهيز جداولها دون إدخال نص قرآني غير موثق.

استخدم migrations، ولا تستخدم FakeRepository أو Mock Data.

## الإعدادات الأساسية
استخدم DataStore لحفظ:

- الوضع الفاتح/الداكن/التلقائي.
- حجم الخط.
- اللغة الحالية.
- تفعيل الإشعارات.
- طريقة حساب الصلاة.
- المذهب.
- تفضيلات الصوت.

## الصلاحيات
جهّز طلب الصلاحيات بطريقة واضحة، دون طلبها عند أول تشغيل بلا سبب:

- الموقع عند فتح ميزة الصلاة أو القبلة.
- الإشعارات في Android 13+ عند تفعيل التنبيهات.
- لا تطلب صلاحيات التخزين القديمة غير اللازمة.

## المطلوب عدم فعله
- لا تنشئ أزرارًا لا تعمل.
- لا تضع TODO بدل التنفيذ الأساسي.
- لا تستخدم بيانات صلاة أو طقس أو قرآن تجريبية.
- لا تضع API Keys داخل الكود.
- لا تنسخ شعارًا أو صورًا أو تصميمًا محفوظًا لتطبيق آخر.

## الاختبارات ومعايير القبول
قبل إنهاء المرحلة:

1. نفّذ `./gradlew assembleDebug` بنجاح.
2. أضف اختبارًا لقاعدة البيانات واختبارًا للإعدادات.
3. تحقق من RTL على جميع الشاشات.
4. تحقق من الوضع الداكن والفاتح.
5. تحقق من التنقل ذهابًا وإيابًا.
6. تحقق من حفظ الإعدادات بعد إغلاق التطبيق.
7. لا توجد شاشات مكسورة أو أخطاء Compose.
