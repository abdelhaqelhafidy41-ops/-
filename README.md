# تطبيق نور المسلم (Noor Al-Muslim)

تطبيق إسلامي شامل وموثوق مبني وفق أعلى معايير هندسة البرمجيات في نظام Android، باستخدام Kotlin وJetpack Compose وMaterial Design 3 وهندسة Clean Architecture بنمط **Offline-First**.

---

## 📱 نظرة عامة على مميزات التطبيق

1. **القرآن الكريم والتلاوات:**
   - السور الـ 114 كاملة بالنص العثماني الموثوق المطابق لمجمع الملك فهد لطباعة المصحف الشريف (بما فيها سورة البقرة كاملة 286 آية وسورة الفاتحة والناس وجميع سور القرآن).
   - تلاوات صوتية موثقة لـ 5 من كبار القراء (العفاسي، الحصري، عبد الباسط، المنشاوي، الغامدي) تعمل عبر `MediaSession` وخدمة خلفية (`ForegroundService`) مع إشعارات التحكم الكاملة.
   - نظام ختمات متقدم مع حساب الورد اليومي ومعدل الإنجاز.
   - نظام متابعة حفظ ومراجعة السور والآيات مع التقييم الذاتي.
   - حفظ موضع القراءة التلقائي والوصول السريع لآخر آية مقروءة.

2. **مواقيت الصلاة والقبلة:**
   - حساب فلكي دقيق 100% لمعادلات جين ميوس الفلكية (Jean Meeus Algorithms) دون الحاجة لأي اتصال بالإنترنت.
   - 5 طرق حساب معتمدة عالمياً (أم القرى بمكة المكرمة، رابطة العالم الإسلامي، الهيئة المصرية العامة للمساحة، جامعة العلوم بكراتشي، وISNA).
   - حساب صلاة العصر بالمذهب الشافعي والمالكي والحنبلي (ظل المثل) وبالمذهب الحنفي (ظل المثلين).
   - إمكانية ضبط وتعديل الدقائق يدوياً لكل صلاة فردياً.
   - بوصلة القبلة الحقيقية المعتمدة على مستشعرات العتاد (`TYPE_ROTATION_VECTOR` و `SensorManager`) مع تنعيم الحركة ومؤشر دقة المعايرة والتنبيه عند غياب المستشعر.
   - تنبيهات الأذان والتذكير الدقيق عبر `AlarmManager` مجدول ومستمر حتى بعد إعادة تشغيل الجهاز (`BootReceiver`).

3. **الأذكار والأدعية والمكتبة الإسلامية:**
   - 12 تصنيفاً شاملاً من حصن المسلم والأدعية النبوية والقرآنية الموثقة بالسند ودرجة الحديث.
   - سبحة إلكترونية تفاعلية مع حفظ الحالة تلقائياً والاهتزاز اللمسي وتحديد الأهداف.
   - مكتبة إسلامية موثقة تضم أمهات الكتب: (رياض الصالحين، الأربعون النووية، الشمائل المحمدية، وحصن المسلم الكامل).
   - بحث شامل في نصوص الأذكار والأحاديث وإضافة سريعة للمفضلة.

4. **الإحصائيات وسجل العبادات والإعدادات:**
   - تتبع العادات والصلوات الخمس بنظام القناع الثنائي (Bitmask).
   - سجل إنجازات يومي وتتبع سلاسل الالتزام (Streak Days).
   - تصدير واستيراد البيانات بصيغة JSON و CSV.
   - تحكم كامل بالمظهر (فاتح، داكن، وتلقائي حسب النظام).
   - 4 مستويات لتكبير الخطوط (100%، 115%، 130%، 150%) مع دعم خطي Cairo و Amiri.

5. **الويدجت والخلفيات الإسلامية (المرحلة السادسة):**
   - 44 ويدجت حقيقي لسطح المكتب عبر 4 عائلات (الصلاة، القرآن، الأذكار، والمرافق).
   - سبحة إلكترونية تفاعلية في الويدجت تزيد العداد فوراً وتحدث قاعدة بيانات التطبيق دون فتحه.
   - شاشة تخصيص لكل ويدجت (`WidgetConfigureActivity`) لتعديل المدينة وطريقة الحساب.
   - مكتبة تضم 162 خلفية إسلامية موثقة ومرخصة عبر 18 تصنيفاً مع إمكانية تعيينها فوراً كشاشة قفل أو شاشة رئيسية وتنزيلها ومشاركتها.

## 🛠️ البناء والتشغيل والـ CI/CD

### 1. المتطلبات:
- Android SDK 36 (Android 16 Developer Preview / Android 14+).
- Min SDK: 24 (يدعم أكثر من 95% من أجهزة الأندرويد النشطة عالمياً).
- Java JDK 21 / 17.
- Gradle 9.3.1.

### 2. البناء المحلي عبر الطرفية:
```bash
# تشغيل جميع الاختبارات الآلية (Robolectric & Unit Tests):
./gradlew testDebugUnitTest

# بناء نسخة الاختبار (Debug APK):
./gradlew assembleDebug

# بناء النسخة النهائية الموقعة (Release APK):
STORE_PASSWORD="android" KEY_PASSWORD="android" ./gradlew assembleRelease
```

- مكان ملفات الـ APK الناتجة:
  - `app/build/outputs/apk/debug/app-debug.apk`
  - `app/build/outputs/apk/release/app-release.apk`

### 3. مسار النشر التلقائي عبر GitHub Actions:
تم تضمين ملف سير العمل `.github/workflows/build_Android.yml` (ونسخة منه في جذر المشروع `build_Android.yml`) والذي يقوم بـ:
1. استنساخ المستودع وتهيئة بيئة Java JDK 21.
2. تهيئة وتثبيت Gradle 9.3.1 وإعطاء الصلاحيات للـ Gradle Wrapper.
3. إنشاء مفاتيح التوقيع الآمنة تلقائياً في حال عدم توفرها.
4. تنفيذ جميع اختبارات الوحدة واختبارات الـ Flows.
5. بناء نسخة Debug ونسخة Release كاملة.
6. رفع النسختين كـ Artifacts جاهزة للتحميل من تبويب Actions في GitHub.

## 🔒 الأمان وحماية الخصوصية
- **Offline-First:** التطبيق يعمل محلياً بالكامل ولا يتطلب أي اتصال بشبكة الإنترنت للوظائف التعبدية الأساسية (القرآن، الأذكار، مواقيت الصلاة، القبلة، الختمات، الخلفيات).
- **Zero Tracking:** لا توجد أي أدوات تتبع أو تحليلات إعلانية أو مكتبات طرف ثالث تجمع بيانات المستخدم.
- **إذن الموقع الجغرافي:** يُستخدم الموقع محلياً على الجهاز فقط لحساب زاوية القبلة ومواقيت الأذان ولا يُرسل لأي خادم خارجي.
- **تشفير واتصال آمن:** التلاوات الصوتية المحملة اختيارياً من قبل المستخدم تستخدم بروتوكول HTTPS المشفر فقط.
