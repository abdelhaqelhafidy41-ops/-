# تطبيق نور المسلم (Noor Al-Muslim)

تطبيق إسلامي شامل وموثوق مبني وفق أعلى معايير هندسة البرمجيات في نظام Android، باستخدام Kotlin وJetpack Compose وMaterial Design 3 وهندسة Clean Architecture.

---

## 🌟 المرحلة الأولى: البنية التحتية والهوية البصرية
1. **هوية بصرية إسلامية أصلية:**
   - لوحة ألوان هادئة: كحلي داكن (`#0B192C`)، أخضر زمردي (`#0E6655`)، ذهبي هادئ (`#9E7C20`)، وأبيض عاجي (`#FAF8F5`).
   - خطوط عربية أصيلة محلياً: خط **Cairo** لواجهات المستخدم وعناوين الشاشات، وخط **Amiri** للنصوص القرآنية والتسبيح.
   - دعم كامل وتلقائي لاتجاه القراءة من اليمين إلى اليسار (**RTL**) على مستوى التطبيق بالكامل.
   - دعم المظهر الفاتح والداكن والوضع التلقائي المتوافق مع إعدادات النظام.
   - دعم تغيير حجم خطوط التطبيق ديناميكياً بأربعة مستويات (100%، 115%، 130%، 150%).

2. **بنية Clean Architecture وMVVM:**
   - فصل كامل بين طبقات البيانات (`data`)، والدومين (`domain`)، والواجهات (`presentation`)، والإعدادات الأساسية (`core`).
   - حقن التبعيات عبر `AppContainer` في كائن `NoorMuslimApp`.

3. **قاعدة بيانات محلية متكاملة (Room Database v1):**
   - 9 كيانات و7 DAOs: إعدادات المستخدم (`user_settings`)، المفضلة (`favorites`)، موضع القراءة (`reading_progress`)، كتالوج وسجل الأذكار (`dhikr_items` و `dhikr_history`)، الإنجازات اليومية (`daily_achievements`)، مواقيت الصلاة المحفوظة (`saved_prayer_times`)، وسور وآيات المصحف (`quran_surahs` و `quran_ayahs`).
   - استعلامات تفاعلية باستخدام Kotlin Coroutines و `Flow`.

4. **تخزين الإعدادات والتفضيلات (DataStore Preferences):**
   - حفظ واسترجاع سريع لتفضيلات المستخدم وطرق الحساب والمذهب والإشعارات والموقع الجغرافي.

## 🕌 المرحلة الثانية: مواقيت الصلاة، والقبلة، والإشعارات

### 1. الحساب الفلكي الدقيق لمواقيت الصلاة (Astronomical Calculation):
- **معادلات فلكية حقيقية 100%:** تطبيق خوارزمية جين ميوس (Jean Meeus Astronomical Algorithms) لحساب موضع الشمس، وميلها (Declination)، ومعادلة الوقت (Equation of Time)، وزاوية الساعة (Hour Angle).
- **الصلوات الست اليومية:** الفجر، الشروق، الظهر، العصر، المغرب، العشاء.
- **طرق الحساب المعتمدة عالمياً:**
  - أم القرى (مكة المكرمة - الفجر 18.5° والعشاء بعد المغرب بـ 90 دقيقة).
  - رابطة العالم الإسلامي (الفجر 18.0° والعشاء 17.0°).
  - الهيئة المصرية العامة للمساحة (الفجر 19.5° والعشاء 17.5°).
  - جامعة العلوم الإسلامية بكراتشي (الفجر 18.0° والعشاء 18.0°).
  - الجمعية الإسلامية لأمريكا الشمالية ISNA (الفجر 15.0° والعشاء 15.0°).
- **حساب العصر بالمذاهب الفقهية:**
  - المذهب الشافعي/المالكي/الحنبلي (ظل المثل: `shadowFactor = 1.0`).
  - المذهب الحنفي (ظل المثلين: `shadowFactor = 2.0`).
- **تعديل يدوي بالدقائق لكل صلاة:** إمكانية زيادة أو إنقاص الدقائق (+/- دقيقة) لكل صلاة فردياً لضبط الفروق المحلية.
- **التنقل بين الأيام:** إمكانية استعراض مواقيت الأيام السابقة والقادمة بكل سلاسة مع زر للعودة لليوم الحالي.
- **العد التنازلي التفاعلي الحي:** كاشف الصلاة القادمة تلقائياً مع معالجة ذكية لما بعد صلاة العشاء والانتقال إلى فجر اليوم التالي.
- **حفظ المواقيت محلياً (Offline First):** كاش في جدول `saved_prayer_times` لقاعدة بيانات Room يضمن عمل التطبيق فوراً بدون إنترنت.

### 2. بوصلة القبلة الحقيقية المعتمدة على المستشعرات (Hardware Qibla Compass):
- **حساب زاوية القبلة:** معادلة الدائرة العظمى (Great-Circle Bearing) الدقيقة تجاه الكعبة المشرفة في مكة المكرمة (`21.4225° N, 39.8262° E`).
- **مستشعرات العتاد الحقيقية:** الاعتماد على `TYPE_ROTATION_VECTOR` مع دعم احتياطي لمزيج مقياس التسارع والمغناطيسية (`TYPE_ACCELEROMETER` + `TYPE_MAGNETIC_FIELD`).
- **تصفية الاهتزاز (Low-Pass Filter):** تنعيم حركة الإبرة لمنع الارتعاش وتوفير تجربة حركة انسيابية وثابتة.
- **معالجة حالات العتاد:**
  - فحص وجود مستشعر المغناطيسية وعرض إشعار تنبيه واضح في حال عدم توفره بالجهاز (بدون أسهم وهمية ثابتة).
  - شارة مستوى دقة المستشعر (عالية، متوسطة، ضعيفة، غير موثوقة).
  - زر إرشادات معايرة المستشعر بحركة شكل 8 الإنجليزية (Figure-8 Calibration Dialog).
  - مؤشر محاذاة القبلة التفاعلي: يضيء باللون الذهبي الزمردي عند دقة الاتجاه ±3 درجات مع نبض حركي واهتزاز خفيف.

### 3. نظام الإشعارات والتنبيهات المتقدم (AlarmManager):
- **قنوات إشعارات مخصصة (Notification Channels):**
  - قناة الأذان الأساسية: `prayer_adhan_channel` (أهمية عالية، صوت أذان واهتزاز).
  - قناة التذكير قبل الأذان: `prayer_pre_adhan_channel` (أهمية متوسطة).
- **جدولة دقيقة بالثانية:** استخدام `AlarmManager.setExactAndAllowWhileIdle()` مع استيفاء أذونات `SCHEDULE_EXACT_ALARM` و `USE_EXACT_ALARM`.
- **مستقبلات النظام لإعادة الجدولة التلقائية:**
  - `PrayerAlarmReceiver`: استقبال موعد الصلاة، إطلاق الإشعار، ثم جدولة اليوم التالي تلقائياً لضمان عدم توقف التنبيهات.
  - `PrayerBootReceiver`: إعادة جدولة كافة مواقيت الصلاة فور إعادة تشغيل الجهاز (`BOOT_COMPLETED`)، أو تغيير المنطقة الزمنية (`TIMEZONE_CHANGED`)، أو تعديل وقت الهاتف (`TIME_SET`).
- **تحكم مرن لكل صلاة:** مفاتيح تفعيل/تعطيل الإشعار لكل صلاة بشكل منفصل، وخيار تذكير مسبق قبل الأذان (بدون، 5، 10، أو 15 دقيقة).

### 4. تكامل الشاشة الرئيسية (Home Screen Integration):
- بطاقة علوية هيدر تعرض التاريخ الهجري الحقيقي المعادل للتاريخ الميلادي واسم اليوم باللغة العربية.
- بطاقة بطل (Hero Card) مميزة للصلاة القادمة مع العد التنازلي المباشر واسم المدينة.
- جدول زمني أفقي مدمج يستعرض مواقيت صلوات اليوم الخمس وحالة كل صلاة (انقضت، الحالية، القادمة).

## 🛠️ متطلبات التشغيل والبناء
- **اللغة:** Kotlin
- **واجهة المستخدم:** Jetpack Compose + Material 3
- **minSdk:** 24 (Android 7.0+)
- **targetSdk / compileSdk:** 36 (Android 16)
- **قاعدة البيانات:** Room 2.7.0 مع معالج KSP
- **التفضيلات:** AndroidX DataStore Preferences 1.1.7
- **التنقل:** Navigation Compose 2.8.9

### أوامر البناء والاختبار:
```bash
# بناء التطبيق في وضع تصحيح الأخطاء (Debug APK):
gradle assembleDebug

# تشغيل اختبارات الوحدة واختبارات Robolectric:
gradle :app:testDebugUnitTest
```

## 🧪 الاختبارات المنفذة (19 اختبار مؤتمت)
- `PrayerCalculatorTest`:
  - اختبار الحساب الفلكي لمواقيت الصلاة في مدن مختلفة (مكة، القاهرة، لندن، طوكيو، نيويورك).
  - اختبار التسلسل المنطقي لصلوات اليوم (الفجر < الشروق < الظهر < العصر < المغرب < العشاء).
  - اختبار الفروق الفقهية لصلاة العصر بين المذهب الحنفي وظل المثل للمذاهب الثلاثة الأخرى.
  - اختبار تأثير طرق الحساب المختلفة على زوايا الفجر والعشاء (أم القرى، رابطة العالم الإسلامي، الهيئة المصرية، كراتشي، ISNA).
  - اختبار الكاشف التلقائي للصلاة القادمة لما بعد منتصف الليل والانتقال لفجر الغد.
  - اختبار إزاحة الدقائق اليدوية والتأكد من تطبيق الزيادة والنقصان بدقة.
  - اختبار استقرار المواقيت الفيزيائية عند اختلاف المناطق الزمنية.
- `QiblaCalculatorTest`:
  - اختبار دقة زاوية القبلة من مدن العالم الرئيسية نحو الكعبة المشرفة بمكة المكرمة:
    - الرياض (~244°)
    - القاهرة (~136°)
    - لندن (~119°)
    - نيويورك (~58°)
    - المدينة المنورة (~178°)
  - اختبار حالة التواجد داخل مكة المكرمة مباشرة (المسافة 0 كم).
  - اختبار صيغة حساب المسافة بالكيلومترات (Haversine Formula).
- `UserPreferencesTest`: اختبارات دقة واستمرارية حفظ تفضيلات المستخدم، وطريقة الحساب، والمذهب، وإزاحات الدقائق، وإعدادات تنبيهات الصلاة.
- `AppDatabaseTest`: اختبارات شاملة لعمليات قاعدة البيانات Room.
- `ExampleRobolectricTest`: اختبار قراءة الموارد وتطابق اسم التطبيق.
